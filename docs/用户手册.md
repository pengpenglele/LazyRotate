# 屏幕方向控制 · 用户手册

适用版本：v1.0 ｜ 包名 `com.lazyrotate.app` ｜ 支持 Android 7.0 及以上

---

## 1. 安装

把 `dist/app-debug.apk` 传到平板上安装（或用 `adb install -r dist/app-debug.apk`）。
首次安装需要在系统里允许「安装未知来源应用」。

---

## 2. 首次设置（约 1 分钟）

### 第 1 步（必做）：授予「修改系统设置」

这是本 App 唯一的能力来源。没有它，所有按钮都不会生效。

1. 打开「屏幕方向控制」。
2. 首页会出现一条提示；点它 → 进入系统的「修改系统设置」页面。
3. 找到「屏幕方向控制」，把开关打开。
4. 返回 App，状态卡会从"未就绪"变成正常状态。

> 为什么需要这个权限：Android 只允许获得此权限的应用修改系统的屏幕旋转设置。本 App 通过关闭「自动旋转」并指定目标角度来工作，不涉及任何其它系统设置。

### 第 2 步（可选）：添加快速设置磁贴

下拉通知栏 → 点右上角编辑（铅笔图标）→ 把「屏幕方向控制」拖到快捷区。

### 第 3 步（可选）：开启悬浮球

App 内「设置」→ 悬浮球 → 按提示授予「显示在其他应用上层」→ 回到 App 打开开关。

### 第 4 步（可选）：开启无障碍服务

只有「按应用规则」需要它。App 内「应用规则」页会提示，点进去开启即可。

> 本服务**只读取当前前台应用的包名**，用来判断"现在该用哪个方向"。不读取屏幕内容、不获取文字/密码、不执行点击。

## 3. 日常使用

### 躺着看视频（最常用）

| 想要的效果 | 怎么做 |
|---|---|
| 别再乱转了 | 点磁贴 / 双击悬浮球 → 「锁定当前方向」 |
| 翻个身，画面倒过来了 | 双击悬浮球 → 「翻转 180°」（或磁贴连点两次） |
| 恢复成系统自动旋转 | 磁贴再点一次 / 主界面点「跟随系统」 |

**磁贴的循环顺序**：跟随系统 → 锁定当前方向 → 翻转 180° → 跟随系统 → ……

### 悬浮球手势

| 操作 | 效果 |
|---|---|
| 单击 | 循环切换（同磁贴） |
| 双击 | 翻转 180° |
| 长按 | 打开 App 主界面 |
| 拖动 | 移动到其它位置（位置会被记住） |

悬浮球会显示一个常驻通知，通知栏里也有「锁定 / 翻转 / 跟随系统」三个按钮。

### 主界面

- **状态卡**：当前是否锁定、锁在哪个角度、自动旋转是否开启。
- **两个大按钮**：「锁定当前方向」「翻转 180°」——躺着单手就能点到。
- **快捷方向**：横屏 / 竖屏 / 反向横屏 / 反向竖屏，以及 0°/90°/180°/270° 四个绝对角度。
- **躺姿引擎**：见下一节。
- **当前前台应用**：显示现在最前面的应用，可以一键为它建立规则。

## 4. 躺姿引擎是什么

系统自带的方向判断在躺姿下会乱转，原因是：当你把平板举在面前时，屏幕接近水平，重力在屏幕平面上的投影很小，系统没有足够信息判断方向。

躺姿引擎的做法是**承认自己不知道**：

- 信息足够 → 按迟滞规则稳定切换（同一个方向要持续约 0.7 秒才切，手抖不会触发）；
- 信息不足 → 显示 **「保持现状」**，屏幕**不动**。

所以看到「保持现状」不是坏了，而是它在正常工作——它选择了不折腾你。要改变方向时，用「锁定」或「翻转」按钮手动指定即可，这两者永远优先于引擎的建议。

## 5. 按应用规则

1. 先在「设置」里开启无障碍服务。
2. 进入「应用规则」页，搜索应用，为它选择方向（例如给某个视频 App 固定「横屏」）。
3. 以后切换到该应用时，会**自动**套用这个方向。

说明：

- 规则只在**应用切换时**生效，不会在你正看着的时候突然抢走控制。
- 规则是"保存着但不生效"还是"正在生效"，界面会明确标注。
- 随时可以把某条规则停用或删除。

## 6. 常见问题（FAQ）

**Q：点了按钮没反应？**
A：九成是没授予「修改系统设置」权限。请回到首页看提示条并授权。App 在缺权限时会给出提示，而不是静默失败。

**Q：为什么有的 App 锁不住 / 强制不了？**
A：因为那个 App 自己在代码里写死了方向。这是 Android 的架构限制——第三方应用无权修改另一个应用的窗口方向，和权限多少无关。可用两种办法绕过：
1. 在 Android 16 及以上的大屏设备上，系统本身已放开这类限制（很多新版 App 已自动适用）；
2. 高级办法（需在电脑上执行一次，之后重启也保留）：
   ```bash
   # 让系统忽略应用自己声明的方向
   adb shell cmd window set-ignore-orientation-request true
   # 如果还是不行，用这条更彻底的：系统无条件采用你设定的方向
   adb shell cmd window fixed-to-user-rotation enabled
   ```
   这两条只能由你在电脑上执行——**App 自己打不开**（该开关由系统内部持有，没有提供公开接口，授予"修改安全设置"权限也不够）。App 的「设置」页里有可复制的命令，照着做即可；想关掉就把 `true`/`enabled` 换成 `false`/`disabled`。

   注意：用了第二条之后，那些把方向写死的应用会被强制旋转，但可能出现黑边（不铺满屏幕），这是系统的正常表现。

**Q：横屏和竖屏反了怎么办？**
A：不同平板的"自然方向"不同（多数平板是横屏，少数是竖屏）。到「设置」里打开「设备自然方向」的手动覆盖开关即可。

**Q：会不会更耗电？**
A：不会。App 不使用任何唤醒锁（WakeLock）。悬浮球常驻时 CPU 占用极低；躺姿引擎只在开启时监听传感器，关闭后立即注销监听。

**Q：会不会上传我的数据？**
A：不会，而且可以从技术上验证——App **没有申请网络权限**，装完可以在系统权限列表里确认。所有设置只存在本机，云备份也已关闭。

**Q：无障碍服务安全吗？**
A：它是**可选项**，只用于「按应用规则」。服务配置里明确关闭了读取窗口内容的能力，只接收"哪个应用到了前台"这一事件，不读取文字、不点击任何东西。不想用可以完全不开，其余功能不受影响。

**Q：重启后还要重新设置吗？**
A：权限和规则会保留。锁定的方向默认在重启后交还系统（可在设置里改为"开机恢复上次锁定"）。

**Q：卸载前要注意什么？**
A：**请先在 App 里点「跟随系统」，再卸载。** 因为本 App 是通过关闭系统的「自动旋转」来实现锁定的；如果卸载时还处于锁定状态，系统会保持"自动旋转关闭"。如果已经卸载了，去系统的「显示 → 自动旋转」里手动打开即可。

**Q：和系统自带的"旋转锁定"有什么区别？**
A：系统锁的是"横屏/竖屏"这个维度，且换边后方向容易反；本 App 锁的是**一个绝对角度**，并提供一键翻转 180°、悬浮球/磁贴快速入口、按应用规则，以及「不确定就不动」的躺姿策略。

---

## 7. 卸载与恢复

1. 打开 App → 点「跟随系统」（重要）。
2. 关闭悬浮球开关。
3. 在系统设置里关闭本 App 的无障碍服务（如果开过）。
4. 正常卸载应用。

如果忘了第 1 步：进入系统「设置 → 显示 → 自动旋转」手动打开即可，不会留下其它痕迹——本 App 只改过这一个系统开关和目标角度这两个标准设置项。

## 8. 高级：外部指令（Tasker / 自动化）

| 指令 | 作用 |
|---|---|
| `com.lazyrotate.app.action.SET_ROTATION` + extra `TARGET` | 切换到指定方向 |
| `com.lazyrotate.app.action.CYCLE` | 循环切换 |
| `com.lazyrotate.app.action.FLIP` | 翻转 180° |

`TARGET` 可取：`follow`、`lock`、`flip`、`portrait`、`landscape`、`portrait_rev`、`landscape_rev`、`angle_0`、`angle_90`、`angle_180`、`angle_270`。

示例：

```bash
adb shell am start -a com.lazyrotate.app.action.SET_ROTATION --es TARGET landscape
adb shell am broadcast -a com.lazyrotate.app.action.FLIP
```
